## Troubleshooting:

IF THE IMAGE LOOKS WRONG:
- Check server console for the full prompt
- Verify Classic-cart-ai-base.jpg exists
- Make sure you selected different options at each step

IF YOU GET AN ERROR:
- Restart the dev server
- Check the API key is still valid
- Look at server console for detailed error messages

IF IT'S STILL GENERATING RANDOM CARTS:
- The old code might be cached
- Do a hard refresh (Cmd+Shift+R)
- Or clear .next folder: rm -rf .next && npm run dev
